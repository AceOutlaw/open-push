# SEQTRAK app — screen inventory (Phase 0, P0-NAV)

Values are what the scratch project showed during P0-NAV. Types: C = continuous (slider/knob), E = enum (picker/stepped), T = toggle.

## Global bar
- Play ▶, BPM field (100; tapping opens BPM/Metronome popup: BPM ▲▼, metronome 1–4 select, CLICK SOUND off/on, VOLUME 0–127, TYPE A…), tabs MASTER / DRUMS / SYNTHS / SAMPLER / PERFORM / SETTINGS, HOME, lock icon.
- GUIDE panel (right, every screen): SOUND, PITCH (or MONO/POLY), PAN, VOLUME knobs + ◀▶ (selected track).

## MASTER
### OVERVIEW
- PATTERN 1–6 (E), VOLUME slider 0–127 (C, = `30 40 66`), SEND: REVERB / DELAY buttons (nav), MASTER EFFECT: category, TYPE (SPX ROOM), DRY/WET BALANCE (C, D63>W), EFFECT 1: category, TYPE (CONTROL FILTER), CUTOFF FREQUENCY CONTROL (C, 0), EFFECT 2: category, TYPE (BEAT REPEAT), COMBINATION (C, 0), COMP / EQ buttons (nav).
### EFFECT (sub-tabs MASTER EFFECT / EFFECT 1 / EFFECT 2) — each has CATEGORY (E), TYPE (E), MAP button; parameter list depends on TYPE
- MASTER EFFECT: CATEGORY REVERB, TYPE SPX ROOM. P1: REVERB TIME 0.8s, DIFFUSION 7, INITIAL DELAY 0.1ms, HPF CUTOFF 32Hz, LPF CUTOFF 12.0kHz, DRY/WET D63>W. P2: REVERB DELAY 0.1ms, DENSITY 2, ER/REV BALANCE E4>R, FEEDBACK HIGH DAMP 0.7, FEEDBACK LEVEL 31.0. (2 pages)
- EFFECT 1: CATEGORY FILTER, TYPE CONTROL FILTER. P1: FILTER TYPE HPF, CUTOFF FREQUENCY CONTROL 0, RESONANCE 38, FILTER OUTPUT LEVEL 0dB, DRY/WET D63>W. (1 page, no MAP)
- EFFECT 2: CATEGORY OTHER, TYPE BEAT REPEAT. P1: REPEAT OFF, LENGTH 1/1, FREEZE OFF, GATE TIME 100%, ATTACK TIME 0%, RELEASE TIME 0%. P2: PLAY SPEED 1.0, PITCH SWEEP 0, DRY/WET D<W63, FILTER TYPE THRU, CUTOFF 1kHz, RESONANCE 0. P3: OUTPUT LEVEL 0dB. (3 pages)
### SEND (sub-tabs SEND 1 REVERB / SEND 2 DELAY)
- REVERB: REVERB TYPE (R3 HALL), RETURN VOL 0–127 knob, MAP button. P1: REVERB TIME 2.4s, DIFFUSION 10, INITIAL DELAY 12.7ms, HPF CUTOFF 180Hz, LPF CUTOFF 7.0kHz, REVERB DELAY 17.4ms. P2: DENSITY 4, ER/REV BALANCE E7>R, FEEDBACK HIGH DAMP 0.9, FEEDBACK LEVEL 31.0. (2 pages)
- DELAY: DELAY TYPE (TEMPO DELAY STEREO), RETURN VOL knob, MAP. P1: DELAY TIME 8th., FEEDBACK LEVEL 42.0, FEEDBACK HIGH DAMP 1, L/R DIFFUSION 1ms, LAG 6ms, EQ LOW FREQUENCY 250Hz. P2: EQ LOW GAIN 0dB, EQ HIGH FREQUENCY 4.0kHz, EQ HIGH GAIN 0dB. (2 pages)
### COMP & EQ (sub-tabs COMP / 5 BAND EQ)
- COMP: COMP TYPE (UNI COMP DOWN), ON/OFF (T, on). Page 1: THRESHOLD -14.5dB, KNEE 8, ATTACK 18.1ms, RELEASE 135.5ms, RATIO 1.50, DRY/WET D<W45. Page 2: OUTPUT LEVEL 0dB, MAKE UP GAIN 2dB, POST-COMP HPF Off, CLIPPER OFF, CLIPPER SOURCE DRY+WET. (2 pages)
- 5 BAND EQ: 5 bands × GAIN (±12 dB slider, 0), FREQ (80 / 200 / 500 / 3.2k / 8.0k Hz), Q (0.7).

## DRUMS (tracks KICK, SNARE, CLAP, HAT1, HAT2, PERC1, PERC2; each shows TYPE badge DRUM / DRUMKIT / SYNTH)
### Overview (per track)
- Track type selector DRUM / DRUMKIT / SYNTH (E — v2.0 track type, KM-34), SOUND name + download icon, PATTERN 1–6 (E), PITCH knob -24…+24 (C), CHOKE off/on (T), PAN L–C–R (C), VOLUME 0–127 (C), ATTACK (C), DECAY (C), FILTER graph: filter type icons (E), FREQ, RES (C), EFFECT: CATEGORY / TYPE (AMP SIMULATOR 2), DRY/WET (C).
### Detail sidebar: PATTERN / SOUND / SOUND DESIGN / EFFECT
- PATTERN: BARS (2), STEPS (32), COPY, PASTE, DELETE (⚠ destructive — skip), MIDI IMPORT / EXPORT (skip), pattern editor 2 rows × 8 steps with per-row micro slider, page dots + BACK/NEXT.
- SOUND: browser — SEARCH, CATEGORY list (KICK, SNARE, RIM, CLAP, SNAP, CLOSED HIHAT, OPEN HIHAT, SHAKER/TAMBOURINE, RIDE, CRASH, TOM, BELL, CONGA/BONGO, WORLD, …), SOUND list with favorite hearts.
- SOUND DESIGN > EQ SEND: GAIN LOW ±12 dB, GAIN HIGH ±12 dB, FREQ LOW 63 Hz–18 kHz (300 Hz), FREQ HIGH (1.00 kHz), SEND 1 0–127, SEND 2 0–127.
- SOUND DESIGN > LFO: DEPTH 0–127, DELAY 0–127, DESTINATION (E, FILTER CUTOFF), TEMPO SYNC off/on (T), SPEED 0–63 (45), SHAPE (E, TRIANGLE).
- EFFECT: CATEGORY (DISTORTION), TYPE (AMP SIMULATOR 2), MAP; P1: OVERDRIVE 80, AMP TYPE OFF, LPF CUTOFF 20.0kHz, OUTPUT LEVEL 52, DRY/WET D63>W. ❓ Same effect shown for KICK and PERC2 — may be one shared drum effect; check in Phase 1.

## SYNTHS / SAMPLER (tracks SYNTH 1, SYNTH 2, DX, SAMPLER)
### Overview (SYNTH 1 / SYNTH 2 / DX)
- SOUND name, PATTERN 1–6, TYPE MONO/POLY (T), CHORD off/on (T) + CHORD▼, PAN, VOLUME, ATTACK, DECAY, FILTER graph (type icons, FREQ, RES), EFFECT CATEGORY/TYPE + one param (DRY/WET or e.g. LFO DEPTH for TEMPO PHASER on SYNTH 2). GUIDE 2nd knob = MONO/POLY/CHORD.
### Detail sidebar (SYNTH 1/2): PATTERN / SOUND / CHORD / SOUND DESIGN / EFFECT
- PATTERN: BARS (1), STEPS (16), COPY/PASTE/DELETE, MIDI IMPORT/EXPORT, piano-roll area + EDIT button.
- CHORD: CHORD MODE off/on (T), CHORD PACK (E), CHORD SELECTOR 7 chord pads (shown: C3 D#3 G3 A#3, D3 F3 G#3 C4, D#3 G3 A#3 D4, F3 G#3 C4 D#4, G3 A#3 D4 F4, G#3 C4 D#4 G4, A#3 D4 F4 G#4).
- SOUND DESIGN sub-tabs: EQ SEND (as drums), LFO, PORTAMENTO (ON/OFF T, TIME 0–127 = 6), ARP (ARP off/on T, MODE ARP / +DIRECT T, TYPE E (UP), SPEED E (100%), GATE 0–200 % (100), OCTAVE -3…+3 (0)).
- EFFECT: as drums.
### DX extra SOUND DESIGN sub-tabs: EQ SEND / ALGORITHM / OPERATORS / PITCH EG / LFO / PORTAMENTO / ARP
- ALGORITHM: 12 algorithm tiles (E; #3 selected).
- OPERATORS: OP1…OP4 (◀▶). Per op: ON/OFF (T), MODE RATIO/FIXED (T), FREQ 0.5–31.99 (C), DETUNE -64…+63 (C), LEVEL 0–127, VEL.S 0–127, FEEDBACK, KSC.R 0–127; EG editor (ATTACK/DECAY1/DECAY2/RELEASE × TIME, LEVEL 0–127); KSC editor (L: DEPTH -127…+127, MODE LIN/EXP; R: DEPTH, MODE).
- PITCH EG: LEVEL1–4 -48…+48, TIME1–4 0–127, per-op ON switches OP1–OP4.
- LFO: DELAY 0–127 (+30), SPEED 0–63 (+13), PMD 0–127 (+6), WAVE (E, SINE), PMD per op ON/OFF ×4, AMD per op 0… ×4.

### SAMPLER (track)
- Overview: PATTERN 1–6, PAN, VOLUME, RECORD SETTINGS: NORMALIZE off/on (T), SOURCE (E, USB), SAMPLES pads 1–7 (pad select), EFFECT CATEGORY/TYPE (WAVE FOLDER) + DRY/WET. GUIDE 1st knob = WAVEFORM.
- Detail sidebar: PATTERN (BARS 2, STEPS 32, COPY/PASTE/DELETE, MIDI IMPORT/EXPORT, EDIT), SOUND DESIGN (FILTER graph FREQ/RES, SEND 1 – REVERB 0–127, SEND 2 – DELAY 0–127), EFFECT.
- ❓ Sample start/end/loop not seen on these pages; maybe behind the pads or the GUIDE WAVEFORM knob. Check in Phase 1.

## PERFORM (sub-pages MIXER / SAMPLER / SEND / PATTERN / PAD/KEY / SONG)
- MIXER: 11 track faders 0–127 + SOLO + MUTE per track (KICK…SAMPLER).
- SAMPLER: SAMPLE 1–7 faders 0–127 + MUTE each.
- SEND: 11 track send faders 0–127, view toggle SEND1 ↔ SEND2.
- PATTERN: 11 tracks × pattern 1–6 grid (launch).
- PAD/KEY: track sub-tabs DRUMS / SYNTH 1 / SYNTH 2 / DX / SAMPLER, PAD ↔ KEYBOARD toggle, 8 pads (plays notes: C3 D3 D#3 F3 G3 G#3 A#3 + 1).
- SONG: scene grid with "+", MODE NORMAL / SONG / SCENE (text says select on device with [ALL]+[PROJECT]), loop button.

## SETTINGS (sub-pages PROJECT / ADVANCED / MIDI)
- PROJECT: PROJECT name field, BPM (100), SWING (68%), KEY (C), SCALE (MINOR), SCALES IN THIS PROJECT editor (8 slots: MINOR, MAJOR, MINOR PENTATONIC, MAJOR PENTATONIC, LYDIAN, DORIAN, MIXOLYDIAN, PHRYGIAN; SCALE LIST to assign), PATTERNS 3 ↔ 6 (T), DRUM CHOKE editor (HAT: HAT1–HAT2 off/on, PERC: PERC1–PERC2 off/on).
- ADVANCED: LIVE REC QUANTIZATION (1/16), ADVANCED SOUND DESIGN (on), NOISE GATE (MIC/LINE IN) (off), COUNT-IN MIDI RECORDING (on), LAUNCH QUANTIZE (16), MASTER FX (MIC/LINE IN) THRU/ON (on), INPUT VELOCITY (100), PLAYBACK MODE AFTER PROJECT SWITCH (OFF), MASTER FX (USB) THRU/ON (on).
- MIDI > COMMON: CLOCK SEND off/on (off), SYNC INTERNAL/EXTERNAL; MIDI > ADVANCED: START/STOP MESSAGE SEND (on); per port (MIDI CABLE / USB / BLUETOOTH): CHANNEL MESSAGE SEND (on) with CONTROL CHANGE / BANK SELECT / PROGRAM CHANGE (ON), SYSTEM EXCLUSIVE SEND (on), THRU MIDI FROM EXTERNAL DEVICE (on). ⚠ Turning off SysEx/CC send may break the bridge — test last, restore immediately.

## HOME
- GUI EDITOR (the tabs above), PROJECT/SOUND MANAGER (PROJECTS: slots 1–8 with BACKUP/DELETE, BACKUP PROJECTS list with LOAD; SOUNDS: user sound library with DELETE; CREATE PROJECT; FULL BACKUP; memory meters) — read-only use only.
- VISUALIZER (3D visuals; NEW/OPEN, SAVE, SETTINGS, MIDI indicator) — not a Seqtrak editor, skip.
- HOME > SETTINGS: APP (RENDER QUALITY, LANGUAGE, ANALYTICS — app-only, skip), HARDWARE (MASTER VOLUME SPEAKER 0–127, OUTPUT GAIN SPEAKER/PHONES -6/0/+6/+12 dB and USB AUDIO -6/0/+6/+12 dB, Wi-Fi MODE CLIENT + COUNTRY, KNOB SENSITIVITY FAST/NORMAL/SLOW, AUTO POWER OFF 30 Min, FIRMWARE VERSION 1.21.3).
- DEVICE CONNECTION (USB / Bluetooth; shows CONNECTED: SEQTRAK), USER MANUAL / PARAMETER LIST / SHORTCUT LIST / FX PRESET LIST / DYNAMIC TUTORIAL (docs, not visited), firmware UPDATE banner (never touch).
